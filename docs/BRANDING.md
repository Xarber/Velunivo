# Velunivo visual identity

**Your route. Your riding speed.** Navigation for e-scooters and e-bikes.

The mark joins a V-shaped path, a round starting point and an upward route arrow. It represents both vehicle types without choosing a scooter silhouette over a bicycle. All geometry is original, editable vector artwork. No third-party vehicle logos or map tiles are embedded in the brand assets.

| Colour | Hex | Use |
| --- | --- | --- |
| Emerald | `#007F6D` | Primary icon background and light-theme accent |
| Mint | `#87E9CA` | Route mark and banner accent |
| Deep green | `#102C2B` | Dark icon, launch screen and banners |
| White | `#FFFFFF` | Arrow tip and foreground contrast |

## Asset locations

- `assets/icon.png` / `assets/icon.svg`: 1024×1024 opaque default app icon, with no baked-in platform corner mask.
- `assets/brand/icon-dark.*`, `icon-tinted.*`: iOS dark and grayscale tinted appearance variants, also opaque 1024×1024.
- `assets/android-icon-foreground.*`: transparent foreground inside the adaptive-icon safe region. Background and monochrome files accompany it; Android applies the launcher mask.
- `assets/brand/mark.*`: transparent logo for presentations.
- `assets/brand/splash-light.*`, `splash.*`: transparent launch marks for the system light/dark backgrounds. Expo splash configuration centres the mark at 180 logical points. Android system splash uses the platform-controlled icon treatment; it is not a full-screen advertisement.
- `assets/favicon.*`: web favicon.
- `docs/brand/banner.*`: 1600×900 README banner.
- `docs/brand/social-preview.*`: 1280×640 GitHub sharing preview.

Run `npm ci` then `npm run brand:generate`. The single source is `scripts/generate-brand.mjs`, which writes both SVG masters and PNG exports using the locked Sharp development dependency. Fonts in SVG banners use Arial/Helvetica with sans-serif fallback; PNGs are the fixed public presentation. Keep the mark’s proportions and sufficient empty space around it. Do not stretch it or crop the arrow.

## Native and web integration

`app.json` configures the icon appearances, Android adaptive/themed icons, favicon and SDK 57 `expo-splash-screen` plugin. Native assets are generated by Continuous Native Generation on the release runners; generated iOS/Android directories are not maintained by hand. The Explore brand card uses the same app icon. Native branding changes require installing a new binary; a web refresh does not change an installed home-screen icon.

The AltSource uses `assets/icon.png` uploaded to the mutable 1.0 release. Its permissions, version metadata and screenshots continue to come from real builds. GitHub description/topics are repository settings; the custom social preview is uploaded in Settings → General → Social preview.

References: [Expo SDK 57 app configuration](https://docs.expo.dev/versions/v57.0.0/config/app/), [splash-screen configuration](https://docs.expo.dev/versions/v57.0.0/sdk/splash-screen/), [GitHub social previews](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

AltSource icons now use a content-addressed icon-<sha256-prefix>.png asset on the 1.0 release, for both the source and app. Future generated feeds refresh these URLs and source metadata; the compatibility icon.png asset is retained. Native iPad screenshots are also included in the iPhone gallery, alongside the dedicated iPad gallery, so tablet imagery is visible from phone clients.
