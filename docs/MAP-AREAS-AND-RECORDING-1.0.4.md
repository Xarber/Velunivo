# Map areas and ride recording (1.0.4)

Library → Downloaded Maps → Download a map area projects a fixed screen square into map coordinates, so pan/zoom select the real bounds rather than an approximate distance. Rotation/pitch are disabled for selection. Photon reverse geocoding names the region using neighborhood/locality where appropriate, city/county and country; the name is editable and lookup failure does not prevent downloading. Initialization waits for stored places, preferring an already-permitted recent GPS fix. No new location permission is requested solely by this page.

Road networks use key-free Overpass and the existing validated/chunked OSM offline graph. Native imagery uses the configured licensed download provider. Downloads retain the existing small-area, size and pack-count limits. Web supports local road networks and cached app assets, not bulk map imagery. The selected area is not a claim of complete POI/traffic coverage or scooter legal access.

The phone/tablet browser picker was inspected at 390×844 and 1180×820. The test exercised actual map projection, fixture reverse naming, download and chunk persistence, and verified controls fit the viewport. A visual pass caught header contrast, overlapping square/card and initial center hydration issues; these were corrected. Four bounded shade rectangles avoid an oversized native shadow raster.

Completed new recordings receive conservative display-geometry cleanup over windows of at most 20 seconds/120 metres. Correction is bounded by accuracy to a maximum four-metre corridor. Stops, interruptions, backward travel and meaningful detours survive. Original GPS, accepted movement fixes and sensor/Bluetooth samples are retained; JSON retains raw observations, while GPX/replay use optional cleaned display coordinates. Old completed rides are not bulk rewritten. Distance/energy statistics are not recalculated from invented motion.

The Explore riding suggestion requires at least four fresh accurate readings, eight seconds of riding-speed movement and twenty metres of accumulated motion. It includes vehicle selection, explicit Start recording, Plan a ride and dismiss. It is once per JS app session, only on idle Explore after onboarding, and uses an ephemeral consent request rather than a public auto-start URL. Walking, poor/stale GPS and stationary drift are covered by tests; physical GPS validation remains pending.

Sharing E-Scooter is permanent, sorts first, has fixed identity/minimal icon and editable limits/tuning. Personal vehicles sort by completed recorded use. Sharing range/picture/Bluetooth menus stay hidden and both new/old pending sharing records are excluded from battery prompts. Usage and distance are actual records; optional car-emissions comparison is explicitly a configurable hypothetical scenario excluding scooter/fleet production and charging.
