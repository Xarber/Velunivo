# In-app changelog history

Settings → What’s New covers every app version from 0.1.0 onward. Entries are curated user-facing summaries, not a dump of technical commits. English and Italian text live in `src/core/releaseHistory.ts`, `src/core/appIntroduction.ts`, and `src/i18n/it.ts`.

Evidence: immutable version tags, conventional commit subjects/diffs, GitHub release inventory, and `docs/WORKLOG.md`. A version tag or documented development build does not prove a binary was published or that every device-specific feature worked. Versions 0.1.1, 0.1.3 and 0.1.4 are reconstructed from documented build boundaries because no corresponding immutable tag was found. Mutable `1.0` is the AltSource feed, not an app version.
