# Security policy

Do not post credentials, pairing material, signing keys, private routes, media or unredacted logs in public issues. Use GitHub's private vulnerability reporting for this repository if available. If it is unavailable, open a public issue requesting a private reporting channel without disclosing exploit details or personal data. Never invent a maintainer email or assume private reporting is enabled.

Report the affected version/commit, platform, reproducible steps and impact using synthetic data. Fixes are evaluated for the latest maintained release; no response-time guarantee is implied. Plugins are untrusted extensions: review capabilities and avoid installing unknown packages. Extended builds do not imply official-store compliance.
